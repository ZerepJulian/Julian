# Script Squad Writer

A lightweight browser app to co-write scripts with friends.

## Features
- Add unlimited scenes.
- Scene headings, action/direction text, and dialogue lines.
- Live full-script preview.
- Autosave to browser localStorage.
- Export/import project JSON files.
- Copy full script text to clipboard.

## Run
Open `index.html` in a browser.

For a local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
